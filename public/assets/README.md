# Risosoo asset library

Place client-owned media into the folders below using these exact filenames. Keep the file extension shown so the website can be wired to each asset predictably. Do not use stock or unlicensed images.

## Brand

- `brand/risosoo-logo.png` — transparent logo; at least 512 × 512 px.

## Hero

- `hero/risosoo-hero-video.mp4` — muted, looping landscape video; 10–20 seconds; 1920 × 1080 minimum.
- `hero/risosoo-hero-poster.jpg` — fallback still image for the video; 1920 × 1080 minimum.

## Destinations

Use portrait images where possible (recommended 1200 × 1600 px):

- `destinations/united-kingdom.jpg`
- `destinations/united-states.jpg`
- `destinations/singapore.jpg`
- `destinations/germany.jpg`
- `destinations/dubai.jpg`
- `destinations/italy.jpg`

## Services

Use a consistent landscape crop (recommended 1600 × 1000 px):

- `services/visa-assistance.jpg`
- `services/study-abroad.jpg`
- `services/flight-reservation.jpg`
- `services/hotel-reservation.jpg`
- `services/work-relocation.jpg`
- `services/travel-consultant.jpg`

## Holiday packages

Name each package image using a lower-case, hyphenated version of the package title, for example:

- `packages/dubai-city-break.jpg`
- `packages/london-study-tour.jpg`

## Blog and testimonials

- `blog/<post-slug>.jpg` — e.g. `blog/uk-visa-application-guide.jpg`; landscape, 1600 × 900 px.
- `testimonials/<client-first-name>.jpg` — optional square portrait, 600 × 600 px.

Once files are in place, let Codex know which ones you added. They will be checked for naming and placed in their matching website sections.
